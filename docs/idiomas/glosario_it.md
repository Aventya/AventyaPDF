# Glossario italiano (it) — AventyaPDF

Riferimenti: Microsoft Language Portal / Windows 11 in italiano, Regolamento (UE) n. 910/2014 (eIDAS) nella versione italiana di EUR-Lex, Adobe Acrobat in italiano.

## Convenzioni generali

- **Registro**: seconda persona singolare (*tu*), come Windows 11 in italiano: «Seleziona», «Riprova», «Fai clic». Comandi di menu e pulsanti all'imperativo («Apri», «Salva», «Stampa»).
- **Messaggi di errore**: forma impersonale «Impossibile + infinito» («Impossibile salvare il file»), come Microsoft.
- **Virgolette**: sempre « » (le stesse dell'originale), mai “ ”.
- **Percentuali**: senza spazio («Zoom 100%»), norma italiana di Microsoft.
- **Puntini di sospensione** «…» conservati nelle voci che aprono una finestra.
- **Plurali con numero**: dove il codice non distingue singolare/plurale si usa la forma «Etichetta: {n}» («Pagine: {n}», «Commenti: {n}»).

## Erratas del original

- «Firmas Certificadas» (pannello laterale): maiuscola non necessaria in spagnolo; tradotto «Firme certificate».
- Non sono stati trovati altri errori evidenti nei testi spagnoli.

## Plurali

- «1 emoji» / «{n} emojis» → «1 emoji» / «{n} emoji» (in italiano «emoji» è invariabile).
- «imagen» / «imágenes» → «immagine» / «immagini».

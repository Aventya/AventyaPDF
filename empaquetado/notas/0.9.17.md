AventyaPDF abre ya libros electrónicos, documentos XPS, dibujos SVG y archivos de texto para guardarlos como PDF. Y al editar el texto de un PDF, la fuente del documento ya no cambia nunca.

> **Solo se mantiene la última versión.** Las anteriores se desechan y se retiran de GitHub; qué trajo cada una está en el [historial de versiones](https://github.com/Aventya/AventyaPDF/blob/main/docs/historial_versiones.md). Si tienes instalada una versión publicada como 1.x (hoy 0.9.6 a 0.9.6.7), tu AventyaPDF no avisará de esta actualización: instálala a mano.

## Instalación
Si ya tienes la 0.9.12 o una posterior, AventyaPDF te avisará de esta versión y la descargará en tu carpeta Descargas: cierra AventyaPDF y abre el archivo para instalarla. Si tienes la 0.9.11, te la instalará él mismo con «Descargar e instalar».

Si no, descarga `AventyaPDF-Setup-0.9.17.exe` y ejecútalo. **Hace falta conexión a Internet durante la instalación**: el instalador solo lleva el código de AventyaPDF y descarga Python, los componentes de Python y las fuentes tipográficas (unos 200 MB) de sus sitios oficiales, comprobando la huella SHA-256 de cada archivo. Instalado ocupa unos 340 MB. Si AventyaPDF está abierto, el instalador pide cerrarlo.

**Firma**: el instalador va firmado con Sigstore por este repositorio (`AventyaPDF-Setup-0.9.17.exe.sigstore.json`, se añade a esta publicación en un par de minutos); cómo comprobarlo, en [docs/verificar_instalador.md](https://github.com/Aventya/AventyaPDF/blob/main/docs/verificar_instalador.md).

Si Windows SmartScreen avisa de «editor desconocido» al descargarlo a mano, pulsa «Más información» → «Ejecutar de todas formas».

Para enviar AventyaPDF a alguien por correo, manda el enlace de esta página: los servidores de correo rechazan cualquier archivo `.exe` adjunto.

## Novedades respecto a la 0.9.16
- **Abrir más tipos de archivo y guardarlos como PDF**: libros electrónicos (EPUB, MOBI, FB2), cómics (CBZ), documentos XPS y OXPS, dibujos SVG y archivos de texto (.txt), además de PDF, imágenes y Word. Se abren con **Archivo › Abrir**, arrastrándolos a la ventana, con «Abrir con…» de Windows o al combinar archivos. Los libros y el texto se reparten en páginas A4 y el índice del libro pasa a los marcadores.
- **Guardar como PDF propone el nombre del original**: la pestaña muestra «libro.epub» (antes «Sin título») y al guardar se propone «libro.pdf» en la misma carpeta. Vale también para imágenes y documentos de Word convertidos.
- **Arrastrar a la ventana** admite también documentos de Word, y **«Abrir con…»** de Windows ya abre imágenes y los demás formatos, no solo PDF.
- **Editar el texto de un PDF nunca cambia la fuente**: se pueden cambiar el tamaño, el color, la negrita y la cursiva, pero siempre con la letra original del documento. Si esa fuente no está instalada, se usa la que trae el propio PDF; si la fuente no tiene alguna letra que has escrito, AventyaPDF avisa y no cambia nada, para que puedas corregirlo. Antes se escribía con la fuente más parecida.
- Si la fuente no tiene versión negrita o cursiva, se simula con la misma letra. Las fuentes estándar del PDF (Helvetica, Times y Courier) se escriben con sus equivalentes de Windows: Arial, Times New Roman y Courier New.
- Se respeta el grosor exacto de la fuente: un texto en Segoe UI Semibold sigue en Semibold (antes pasaba a Bold).
